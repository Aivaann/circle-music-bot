# Музыка для кружочков

Бот, который подкладывает музыку под видеосообщения («кружочки») в
Telegram Business.

```
кружочек из телефона в личном чате
        │
        ▼ business_message
   скачивание mp4 через getFile
        │
        ▼ ffmpeg: голос + музыка (amix), AAC, видео без перекодирования
        │
        ▼ sendVideoNote от имени аккаунта
        │
        └─ исходный кружочек удаляется
```

## Что умеет

- ловит исходящий кружочек в Business-чате и переотправляет его с музыкой;
- сохраняет голос, музыка играет фоном (громкость настраивается);
- удаляет оригинал, чтобы в чате осталась одна версия;
- возвращает кружочек с музыкой, если отправить его самому боту — удобно
  для проверки без Business;
- `/music` — трек, громкость, голос, удаление оригинала;
- при запуске убирает оставшуюся от прежней версии панель кнопок
  (`ReplyKeyboardRemove`) и ставит меню команд `/start`, `/music`;
- сам перезапускается, если сеть до Telegram отвалилась.

## Быстрый старт

1. Установить зависимости:
   ```
   py -m pip install -r requirements.txt
   winget install Gyan.FFmpeg
   ```
   После установки ffmpeg перезапустите терминал (или укажите путь в
   `FFMPEG_PATH` в `.env`).
2. Скопировать `.env.example` в `.env`, заполнить `BOT_TOKEN` и `OWNER_ID`.
3. В @BotFather включить бизнес-режим: `/mybots` → бот → Bot Settings →
   Business Mode.
4. В Telegram: Настройки → Telegram Business → Чат-боты → добавить бота.
   Для удаления оригинала нужно право «Удалять все сообщения».
5. Положить треки в `music/` (mp3, m4a, aac, ogg, opus, wav, flac).
6. Запустить:
   ```
   py main.py
   ```
7. Открыть чат с ботом: `/start` — краткая справка, `/music` — настройки.

Если выбранный трек удалить из папки, бот перейдёт на случайный.

## Как это устроено

- `main.py` — бот: Business-апдейты, `/music`, скачивание и отправка.
- `video_note_music.py` — ffmpeg: `ffprobe` для длительности, `amix` для
  голоса и музыки, AAC 48 кГц, видео копируется (`-c:v copy`).
- `settings.json` — выбранный трек, громкость, флаги и id своих кружочков,
  чтобы не обрабатывать их эхо.
- `music/` — треки, в git не попадают.

## Ограничения

- кружочек не больше 20 МБ — это лимит скачивания Bot API;
- длительность до 60 секунд (ограничение Telegram на кружочки);
- нужен установленный `ffmpeg`;
- удаление оригинала требует права «Удалять все сообщения» у
  Business-бота; без него останутся обе версии;
- бот видит только новые сообщения и только в подключённых Business-чатах;
- одновременно должен работать один экземпляр бота (`Conflict: getUpdates`).
