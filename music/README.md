# Музыка для кружочков

Сюда кладутся треки, которые бот подкладывает под видеосообщения.

Подходят: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.oga`, `.opus`, `.wav`, `.flac`.

Бот берёт случайный трек (или выбранный в `/music`), зацикливает его,
если он короче кружочка, и делает плавное появление и затухание.

Файлы из этой папки не попадают в git — они личные.
